# 结局

## 牺牲锚定-真结局
### 解锁条件
- 研究进度 ≥ 90%
- 所有实验体异化 = 100%（观测丢失）

### Overview
主角启动“最终协议”，选择以自己的意识作为“时间信标”，强行锚定回陨石坠落前的世界线。
在巨大时空压力下，主角作为“变量”被彻底擦除，换来的是
陨石从未坠落
RW 从未出现
BNU 从未崛起
世界安稳如常
唯一的代价：主角被世界遗忘，不再存在于任何记录中。

### Key idea
“世界被拯救，但你不再属于它。”

## 共存选择-中立结局
### 解锁条件
- 研究进度 ≥ 70%
- 至少 1 名实验体异化 ≥ 75%
- 未全部失控

### Overview
主角拒绝重置世界，而选择以 RW 的“擦除或者重写”能力重构现实：
部分人类被改造，与异化体共存
迷雾不再蔓延，但仍存在
世界进入“混合文明时代”
BNU 成为新的秩序管理者
主角成为“调停者”，监督人类与异化体间的平衡
这是一个没有恢复过去，也没有完全崩毁的新世界。

### 最终画面
主角站在新都市的高空天桥上，观察人类与异化体共同生活的街景。
广告牌上出现 RW 新版本的蓝光，象征“新的文明循环”正在发生。

### Key idea
“人类无需回到过去，他们能学会与未来共存。”

## 悲剧结局
### 解锁条件
- 研究进度 < 40%
- 第 4 天后出现实验体失控

### Overview
在关键节点，主角犹豫了。
协议未能成功，RW 程序失控，奇点之门崩塌。
时间线瓦解
世界分裂成无数碎片
所有现实被不断重演又毁灭
主角被卷入时空裂隙中，成为“永恒观察者”：
一个被困在无尽可能世界里，看着无数灾难与失败循环的存在。

### 最终画面
主角漂浮在无光的裂隙中，手中紧握的家人照片逐渐化为迷雾。
远处，小咪的异化幻影注视着他，既像同伴，也像审判。

### Key idea
“当你无法选择未来时，你只能被未来吞噬。”

## 隐藏结局
### 解锁条件
- 研究进度 ≥ 95%
- 小咪异化 = 100%
- 马楼与钢铁志愿异化 ≥ 75%

### Overview
在启动协议之前，主角做出一个违背常理的选择：
将“擦除能力”与“小咪的意识”融合。
最终协议成功，但牺牲者不是主角，而是主角的存在仍然被抹除，但小咪保留了 RW 的全部能力，成为“时间守望者”。
世界得到了重置，但 RW 的力量以“猫的形态”继续存在。

### 最终画面
城市恢复平稳。
夜幕下，重置后的 BNU 大厦顶端，一只普通而又不普通的小咪坐着，眼中倒映着星空的碎片。它默默守望着时间线，守着一个早已不存在的人。

### Key idea
“拯救世界的人消失了，只留下守护记忆的那只小咪。”
