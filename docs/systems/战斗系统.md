# 战斗系统

## 目的与范围
- 定义回合制战斗的核心机制，包括伤害计算、属性克制、状态效果与技能系统。
- 涵盖 Buff/Debuff、护盾、持续伤害(DOT)、技能冷却与特殊效果的完整实现。
- 为养成系统提供经验值获取途径，与实验体进化系统联动。

## 背景
- 玩家通过"神经连接"系统与培养的实验体同步，操控实验体参与回合制战斗。
- 战斗发生在异化实验室的虚拟训练场，败北时实验体生命值重置（模拟训练保护）。
- 胜利后实验体获得经验值成长，并有机会触发进化。

## 核心机制

### 战斗流程
1. **遭遇触发**：玩家点击"战斗训练"按钮进入战斗覆盖层
2. **初始化**：
   - 随机选择敌方实验体（从全实验体池中随机）
   - 硬币判定先后手（50% 概率）
   - 初始化双方状态（HP、护盾、Buff、DOT等）
3. **回合循环**：
   - 回合开始时处理 DOT、Buff时效、CD递减
   - 玩家回合：选择技能或使用物品
   - 敌方回合：AI 随机选择可用技能
   - 检查胜负条件
4. **战斗结束**：
   - 胜利：实验体满血恢复，获得 400 经验值，可能触发升级/进化
   - 失败：实验体满血恢复（模拟训练保护），无经验奖励

### 属性克制系统
继承实验体系统的克制关系：
- 量子 → 火焰 → 合金 → 雷电 → 量子（1.5倍伤害）
- 超能：不弱任何属性，免疫量子任何伤害（0倍）

### 伤害计算
```
基础伤害 = 技能基础值
特殊效果调整（硬币判定、条件加成等）
属性克制倍率
Buff/Debuff 加成倍率
最终伤害 = floor(基础伤害 × 所有倍率)
```

伤害分配优先级：
1. 护盾优先吸收
2. 剩余伤害扣除 HP
3. 触发反击/反伤效果（如有）

## 状态系统

### Buff（增益效果）
- **攻击提升** (atk_boost)：伤害倍率增加，如自燃升温(+25%)、升压(+20%)
- **护盾** (shield)：数值型护盾，优先吸收伤害
- **反击** (counter)：受到伤害时回击固定值或百分比伤害
- **荆棘** (thorns)：被击中时对攻击者造成固定反伤
- **闪避** (evasion)：提升闪避率（暂未完全实现）
- **必中** (accuracy)：下回合攻击必定命中

Buff 数据结构：
```javascript
{
  name: "buff名称",
  type: "buff类型",
  value: 数值,
  duration: 剩余回合数
}
```

### Debuff（减益效果）
- **攻击降低** (atk_reduce)：伤害倍率降低，如静默场(-20%)、干扰射频(-15%)
- 实现方式同 Buff，但存储在同一数组中，通过 type 区分

### DOT（持续伤害）
- 每回合开始时自动结算
- 支持多个 DOT 叠加
- 典型 DOT：灼咬(20/回合×2)、青青草地(20/回合×3)

DOT 数据结构：
```javascript
{
  name: "dot名称",
  value: 每回合伤害,
  duration: 剩余回合数
}
```

### 护盾系统
- 独立数值，优先于 HP 吸收伤害
- 多次施加护盾会累加
- 部分技能可破坏护盾（溶断、暗焰刺等）

### 眩晕 (Stun)
- 被眩晕的单位跳过行动
- 回合开始时自动解除
- 典型技能：过载（自我眩晕1回合）

### 技能冷却 (CD)
- 部分强力技能使用后进入冷却
- CD 期间无法使用该技能
- 每回合开始时 CD -1

## 技能系统

### 技能分类
1. **伤害技能** (damage)：造成直接伤害
2. **治疗技能** (heal)：恢复己方 HP
3. **Buff技能** (buff)：施加增益效果
4. **Debuff技能** (debuff)：施加减益效果
5. **DOT技能** (dot)：施加持续伤害
6. **特殊技能** (special)：复合效果或特殊机制

### 特殊技能效果实现

#### 条件额外伤害
- **干涉尾击**：对合金 +20
- **熔波**：对合金 +30
- **金属咬合**：对火焰 +15
- **烧蚀**：对雷电 +20
- **导线啄**：对量子 +15
- **磁暴**：对合金 +20

#### 护盾相关
- **静默落雷**：对有护盾目标伤害翻倍
- **溶断**：破坏对方所有护盾
- **暗焰刺**：清空对方护盾

#### 技能复制
- **回声视野**：复制对手上回合使用的技能
- **口令复述**：复制对手的基础攻击技能

#### 状态交换
- **相位移**：交换双方所有 Buff/Debuff

#### 概率触发
- **递归喙击**：50% 概率触发额外 30 点伤害
- **挠**：抛硬币 3 次，伤害 = 40 × 正面次数

#### 反击/反伤
- **静电罩**：反弹 50% 近战伤害
- **黑烟掩护**：被击中时反伤 15
- **反击姿态**：受到伤害时回击 50

## 物品系统

### 治疗类
- **纳米修补剂(白)**：恢复 80 HP
- **纳米修补剂(蓝)**：恢复 160 HP

### Buff类
- **过载注射(白)**：攻击+15%，持续 2 回合

使用物品会消耗玩家回合。

## 数据结构

### CombatSession 类
```javascript
{
  player: SubjectInstance,        // 玩家实验体
  enemy: SubjectInstance,         // 敌方实验体
  state: String,                  // 'INIT'/'PLAYER_ACT'/'ENEMY_ACT'/'END_WIN'/'END_LOSS'
  turnCount: Number,              // 当前回合数

  // 状态系统
  buffs: { player: [], enemy: [] },
  shields: { player: 0, enemy: 0 },
  dots: { player: [], enemy: [] },
  cooldowns: { player: {}, enemy: {} },
  stunned: { player: false, enemy: false },
  lastSkillUsed: { player: null, enemy: null }
}
```

### 技能数据库 (SKILL_DB)
```javascript
{
  "skill_id": {
    name: "技能名称",
    type: "技能类型",
    val: 数值,
    desc: "描述",
    cd: 冷却回合数,
    duration: 持续回合数,
    // 特殊字段
    selfDmg: 自伤值,
    dotVal: DOT伤害值,
    logic: "特殊逻辑标识"
  }
}
```

## UI 展示

### 战斗界面组成
- **顶部**：神经连接状态提示 + 断开连接按钮
- **战斗场景区**：
  - 敌方单位：名称、属性、HP条、护盾值、Buff/DOT标签
  - 己方单位：名称、属性、HP条、护盾值、Buff/DOT标签
  - 占位立绘框（当前为占位框）
- **底部控制区**：
  - 左侧：战斗日志（可滚动）
  - 右侧：技能面板（展示所有可用技能 + 描述）

### 状态标签
- **Buff 标签**：蓝色边框，显示名称和剩余回合数
- **DOT 标签**：红色边框，带火焰图标，显示名称和剩余回合数
- **护盾**：在 HP 文本旁显示 `+XX🛡️`

## 接口与事件

### 核心方法
- `start()`：初始化战斗，硬币判定先手
- `nextTurn()`：进入下一回合
- `processTurnStart()`：处理回合开始时的 DOT、Buff、CD
- `playerAction(skillId)`：玩家使用技能
- `useItem(itemId)`：玩家使用物品
- `executeSkill(attacker, defender, skillId, ...)`：执行技能效果
- `checkEnd()`：检查胜负条件

### 回调系统
- `onLog(text)`：输出战斗日志
- `onUpdate()`：刷新 UI
- `onEvent(type, data)`：触发视觉效果（伤害数字、治疗特效等）
